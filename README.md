# Wanderlust 🏡

Wanderlust is an Airbnb-inspired full-stack web application where users
can explore vacation listings, create their own listings, upload images,
view locations on a map, and add reviews and ratings.

## Live Demo

https://wanderlust-hh3s.onrender.com

## Features

- User signup, login and logout
- Create, edit and delete listings
- Image upload using Cloudinary
- Interactive maps using Mapbox
- Location geocoding
- Search listings
- Category filtering
- Tax calculation toggle
- Add and delete reviews
- 1–5 star ratings
- Authentication and authorization
- Owner-based access control
- Joi validation
- Centralized error handling
